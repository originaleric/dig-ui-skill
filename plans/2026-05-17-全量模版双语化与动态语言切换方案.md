# 2026-05-17 全量模版双语化与动态语言切换方案

我们将在 `dig-ui-skill` 中实现无缝、高性能的双语（中/英文）设计系统架构。本方案涵盖了如何修改 Markdown 目录文件以支持双语定义、更新 HTML 模版以支持原生翻译标签、注入精致的浮动毛玻璃语言切换器，以及升级 Python 同步引擎（`sync_renders.py`）以全自动编译本地语言页面和主手册导航中心。

## 🎯 核心架构亮点

1. **AI 友好型双语配置**：支持在 Markdown Frontmatter 中定义 `description_zh` 和 `description_en`。即使旧的第三方模版只定义了 `description`，编译引擎也会通过**智能字元扫描（检测中文字符）**自动降级兼容，零心智负担。
2. **毛玻璃炫彩切换组件**：在所有 HTML 渲染页面与 Hub 首页右上角注入一个浮动的**毛玻璃中/英文切换胶囊**（完全基于 `--dig-*` 变量，自动融合各品牌独特的视觉质感，如 Stripe 的靛蓝、Claude 的珊瑚红）。
3. **零延迟运行时切换**：切换完全是静态、本地且微秒级的。使用 HTML5 `data-zh`/`data-en` 属性，并结合 `localStorage` 自动跨页面同步与记住用户的语言偏好。
4. **全自动索引同步**：重构 `sync_renders.py`，不仅同步各品牌的 HTML，更能**一键自动重新生成 `renders/index.html` 的双语数据库**，保证手册中心的数据 100% 颗粒度一致。

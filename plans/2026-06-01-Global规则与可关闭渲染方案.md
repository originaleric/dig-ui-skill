# Dig UI Global Rules 与可关闭渲染方案

## Summary

新增“Global Rules”规则层，并让它默认参与 AI 生成/审查与 layout render。为审查和对照场景增加一个显式关闭入口：render 时可加参数生成“不包含 global rules”的 HTML；用户在对话中也可以要求“不使用 global”，此时 AI 只按 catalog/layout/primitives 执行。

## Key Changes

- 新增 `references/global-rules.md` 作为默认全局规则入口，包含 i18n、dark/light、药丸按钮、原生 React select/option 等规则。
- 新增 `references/global-rules.local.example.md`，约定用户可创建 `references/global-rules.local.md` 做本地自定义；该本地文件加入 `.gitignore`。
- 更新 `SKILL.md` 和 `USAGE.md`：
  - 默认读取 `global-rules.md`，再读取 `global-rules.local.md`。
  - 优先级：用户当前 prompt > `global-rules.local.md` > `global-rules.md` > catalog > layout/primitives。
  - 如果用户明确说“不使用 global / skip global / no global rules”，本次任务跳过 global rules。

## Render Config

- 更新 `sync-renders.sh` 与 `sync_layout_renders.py`，新增 layout render 参数：
  - `./sync-renders.sh --layouts --no-global`
  - `./sync-renders.sh layout dashboard-overview --no-global`
- 默认 render 仍包含 global rules。
- 使用 `--no-global` 时：
  - 不读取 `global-rules.md` 和 `global-rules.local.md`。
  - HTML notes 区显示 `Global Rules: disabled for review`。
  - HTML 注入 `data-global-rules-enabled="false"`，供 validator 判断。
- 正常 render 时：
  - HTML notes 区新增 `Global Rules` 卡片，展示当前生效规则摘要和来源。
  - HTML 注入 `data-global-rules-enabled="true"` 与规则 manifest。

## Preview & Validation Sync

- 更新 `assets/layout-preview.css`：
  - 默认 primitive 遵循 global rules：按钮使用 pill，新增 `.dig-select` 原生 select 样式。
- 更新 `validate-dig-layout-preview.mjs`：
  - 当 HTML 标记 `data-global-rules-enabled="true"` 时，检查按钮 pill、原生 select 等 global 规则。
  - 当 HTML 标记为 `false` 时，跳过 global-only 检查，只保留 layout 基础检查：slot、横向滚动、tap target、focus-visible、文本溢出等。
- `npm run validate:layouts` 默认校验包含 global 的 render；审查无 global 版本时可直接传单个 HTML 或目录给 validator。

## Test Plan

- 运行 `./sync-renders.sh layout dashboard-overview`，确认 HTML 包含 Global Rules 卡片与 manifest。
- 运行 `./sync-renders.sh layout dashboard-overview --no-global`，确认 HTML 显示 global disabled，且不触发 global-only validator 规则。
- 运行 `npm run validate:layouts`，确认默认 render 无新增 FAIL。
- 创建临时 `references/global-rules.local.md` 覆写一条规则，确认默认 render 生效，`--no-global` render 不生效。
- 人工验证对话规则：用户要求“不使用 global”时，AI 计划和实现不引用 global rules。

## Assumptions

- `--no-global` 只影响 layout render 链；catalog HTML 预览暂不改造。
- 默认行为保持开启 global rules，关闭必须显式声明。
- `--no-global` 生成的是同一路径 HTML 的审查版本，会覆盖当前 layout render；如需同时保留两套 HTML，后续可再加 `--variant no-global`。

# Dig Workflows

Workflow references define how agents should sequence Dig UI work.

## Available Workflows

- `review.md`: review an existing UI against Dig rules.
- `redesign.md`: improve an existing screen while preserving product intent.
- `execution.md`: build or review execution, runtime, observability, and agent-run views.
- `image-reference.md`: use visual references without copying unrelated style systems.

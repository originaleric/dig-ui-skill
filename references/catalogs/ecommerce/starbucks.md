# Design System Inspired by Starbucks

## 1. Visual Theme & Atmosphere

星巴克的设计系统是一个**温暖、自信的零售旗舰**，店面的每个表面都采用绿色围裙。画布在中性暖奶油色 (`#f2f0eb`) 和陶瓷灰白色 (`#edebe9`) 之间交替，颜色参考实际商店材料：餐巾纸、咖啡馆墙壁、木质饰面，而标志性的 **星巴克绿** (`#006241`) 则将品牌时刻锚定在英雄乐队、CTA 和奖励体验上。绿色有四种经过校准的色调（星巴克色、口音、House、Uplift），每种颜色都映射到特定的表面角色，而金色（“#cba258”）仅出现在奖励状态仪式周围，而不是作为一般口音。

版式承载了大部分品牌声音。专有的 **SoDoSans** 字体（为星巴克定制）几乎遍布所有表面，字母间距紧密的“-0.16px”——它读起来自信而友好，而不是时尚杂志上的严肃。不同寻常的是：“奖励”页面在特定的标题时刻切换到温暖的衬线（“Lander Tall”、“Iowan Old Style”、Georgia”），巧妙地呼应了咖啡馆黑板的怀旧感觉。职业页面使用手写体（“Kalam”、“Comic Sans MS”、草书体）来标注个人杯名。三种字体，三种上下文——系统对每种字体的出现时间都有严格的规定。

表面通过圆形几何形状呼吸。每个按钮都是一个 50px 的完整药丸。卡片采用 12px 圆角矩形。 “Frap”浮动 CTA — 绿色口音 (#00754A`) 中的 56px 圆形订单按钮 — 是该产品的标志性深度移动：它在右下角浮动，带有分层阴影堆栈（`0 0 6px rgba(0,0,0,0.24)` 基础 + `0 8px 12px rgba(0,0,0,0.14)` 环境）并通过压缩按下时显示“比例(0.95)”。海拔高度受到限制——卡片阴影保持在低声的“0.14/0.24”alpha，全局导航得到安静的三层阴影堆栈。整个系统感觉就像干净的咖啡馆标牌：清晰、温暖，而且从不喧闹。

**主要特征：**
- 四层绿色品牌系统（星巴克/Accent/House/Uplift），每个系统都映射到不同的表面角色——而不是单一的“品牌绿色”
- 金币仅保留给奖励状态时刻；绝不是通用口音
- 暖中性帆布 (`#f2f0eb` / `#edebe9`) 而不是冷白色 — 参考咖啡馆材料
- 自定义专有字体（SoDoSans），以严格的“-0.16px”字母间距作为通用语音
- 上下文特定的类型开关：衬线（Lander Tall）用于奖励，脚本（Kalam）用于职业杯名称
- 全药丸按钮（`50px`半径）通用，`scale(0.95)`主动按下签名微交互
- 浮动“Frap”圆形 CTA（`56px`、绿色强调色填充、分层阴影堆栈）— 产品的标志性立面元素
- 礼品卡表面设计为**拍照的实物产品** - 每张卡片都是一张独特的插图照片，而不是生成的图形
- 12 像素卡片半径 + 耳语般柔和的阴影使内容卡片保持平坦且有提升提示
- 基于 Rem 的间距比例锚定在 1.6rem (~16px) = `--space-3`，步进到 6.4rem (~64px)

**色块页面节奏：** 奶油色英雄 → 白色内容部分 → 带有白色文本的深绿色（`#1E3932`）功能带 → 奶油色实用区域 → 带有金色/白色文本的深绿色（`#1E3932`）页脚 - 明亮主体周围的浓咖啡深色书立。## 2. Color Palette & Roles

**分析的来源页面：**主页、奖励、礼品卡、产品详细信息（粉红能量饮料）、产品营养（冷萃咖啡）。### Primary
- **星巴克绿** (`#006241`)：历史悠久的品牌绿色。用于 h1 标题、奖励页面上的主要部分标题，以及在需要单一主色的地方作为主要品牌信号。
- **绿色口音** (`#00754A`)：稍微明亮、更明亮的绿色。主要填充 CTA 颜色（“探索我们的下午菜单”、“查看春季菜单”）和浮动 Frap 圆形按钮的填充。
- **House Green** (`#1E3932`)：深近黑色的品牌绿色。页脚表面、功能带背景、奖励状态深色表面以及奖励上的标题“免费咖啡只是开始”英雄带。
- **绿色提升** (`#2b5148`)：次要的中深绿色，少量用于装饰性口音和深色渐变时刻。
- **绿光**（`#d4e9e2`）：浅薄荷色，用于形式有效状态色调和浅绿色实用表面。### Secondary & Accent
- **金色** (`#cba258`)：几乎专门用于奖励状态仪式 - 黄金级标注、合作伙伴徽章（“飞凡里程常客计划”、“旅享家”）和高级感装饰。绝不是通用的品牌颜色。
- **金光** (`#dfc49d`)：较软的金色，用于金色层部分的背景清洗。
- **Gold Lightest** (`#faf6ee`)：在奖励页面的合作伙伴部分使用奶油金色页面表面清洗 - 将金色口音重新融入温暖的中性系统。### Surface & Background
- **白色** (`#ffffff`)：主卡和模态表面。还可以在礼品卡图块上填充卡片。
- **中性冷色** (`#f9f9f9`)：下拉菜单（“帐户”下拉菜单）、表格卡片包装和安静的实用工具容器上使用的微妙冷灰色表面。
- **中性温暖**（`#f2f0eb`）：奖励实用区和英雄乐队的温暖奶油色**主页面画布**。
- **陶瓷** (`#edebe9`)：稍微温暖/深色的奶油色，用于区域分隔符、柔软的页面部分清洗和奖励合作带。
- **黑色** (`#000000`)：为深色页面顶部 CTA 条（“立即加入”）和高对比度顶部导航登录按钮保留的深墨水。### Neutrals & Text
- **文本黑色** (`rgba(0, 0, 0, 0.87)`)：浅色表面上的主标题和正文文本颜色。不是纯黑色——不透明度为 87% 的黑色，看起来更温暖。
- **Text Black Soft** (`rgba(0, 0, 0, 0.58)`)：浅色表面上的辅助/元数据文本。
- **文本白色**（`rgba(255, 255, 255, 1)`）：深绿色表面上的主标题/正文文本。
- **文本白色软**（`rgba(255, 255, 255, 0.70)`）：深绿色表面上的辅助文本 - 页脚链接描述、标题文本。
- **奖励绿色** (`#33433d`)：一种专用的柔和的石板绿色，仅用于奖励页面文本块 - 比文本黑色稍微“多尘”的阅读颜色，表示“奖励表面”，而不使用完整的星巴克绿色。### Semantic & Accent
- **红色** (`#c82014`)：错误和破坏性状态（形成无效的破坏性操作）。
- **黄色** (`#fbbc05`)：警告状态，传统品牌接触。
- **绿灯**（`#d4e9e2` at 33% opacity = `hsl(160 32% 87% / 33%)`）：形成有效字段色调背景。
- **红色色调** (`hsl(4 82% 43% / 5%)`)：表单上的无效字段色调。### Black / White Alpha Ladders
用于覆盖和辅助文本使用的两个平行半透明比例：
- `rgba(0,0,0,0.06)` 到 `rgba(0,0,0,0.90)` 以 10% 的步长 — 用于浅色表面上的深色覆盖
- `rgba(255,255,255,0.10)` 到 `rgba(255,255,255,0.90)` 以 10% 的步长 — 用于深色表面上的浅色叠加### Gradient System
没有观察到结构梯度标记。表面层次结构始终是纯色块——系统依赖于其五层奶油色/绿色表面调色板而不是渐变。## 3. Typography Rules



### 字体家族
- **主要：** `SoDoSans、“Helvetica Neue”、Helvetica、Arial、sans-serif` — 星巴克专有的企业字体，几乎用于所有表面
- **加载后备：** `"Helvetica Neue"、Helvetica、Arial、sans-serif` — 用户在 SoDoSans 加载之前看到的内容
- **奖励衬线：** `“Lander Tall”、“Iowan Old Style”、Georgia、衬线` — 用于特定奖励页面标题时刻，营造温暖的社论感觉
- **职业脚本：** `“Kalam”、“Comic Sans MS”、草书` — 专门用于职业页面“杯子名称”装饰风格，引用星巴克杯子上的手写名称

没有在 `:root` 处显式激活 OpenType 风格集。### 字体层级

**字母间距标记：**
- `letterSpacingNormal`: `-0.01em` （默认值 - 紧密，特征）
- `letterSpacingLoose`: `0.1em` (强调大写)
- `letterSpacingLooser`: `0.15em` （大写样式标签，极度强调）

**行高标记：**
- `lineHeightNormal`: `1.5` (主体)
- `lineHeightCompact`: `1.2` (显示/按钮)### 排版原则
- **严格的负跟踪（`-0.01em`）**几乎普遍应用 - 整个产品读起来稍微压缩，这给了 SoDoSans 自信的存在而不会感到挤压。
- **权重变化带来层次结构，而不是尺寸变化。** H1 和 H2 共享相同的 24px/36px 尺寸；只有重量（600 与 400）和颜色（星巴克绿与文字黑）将它们分开。
- **大小标记使用 rem，锚定到本网站上的 `1rem = 10px`** （通过 `font-size: 62.5%` 根技巧）。因此 `1.6rem` = 16px，`2.4rem` = 24px 等。比例是语义的（textSize-1 到 textSize-10），而不是任意像素值。
- **特定于上下文的字体交换** - 奖励上的衬线，职业上的脚本 - 是经过深思熟虑和本地化的。切勿将它们与同一表面内的主要 sans 混合。
- **正文永远不会变成纯黑色** - 它位于“rgba(0,0,0,0.87)”以匹配暖中性画布温度。### 字体备选说明
SoDoSans 是星巴克专有的（由 House Industries 许可，不公开）。合理的开源替代品：
- **Inter** (Google Fonts) — 类似的人文几何比例，粗细范围宽
- **Manrope** — 稍圆，类似自信的感觉
- **Nunito Sans** — 更温暖，适合“咖啡馆”品牌替代品

如果替换，请验证严格的“-0.01em”/“-0.16px”跟踪是否仍然可读；一些开源字体需要“-0.005em”。

Lander Tall（Rewards Serif）是自定义的 - 开源替代品：**Iowan Old Style**（已处于后备状态）、**Lora** 或 **Source Serif Pro**。 Kalam（职业脚本）可直接在 Google Fonts 上使用。## 4. Component Stylings

### 推荐事项
- 使用中性暖色 (`#f2f0eb`) 或陶瓷 (`#edebe9`) 作为页面画布，而不是纯白色 - 暖奶油色是标志
- 将绿色层映射到其预期的表面角色 - 星巴克绿色用于标题，绿色口音用于 CTA，House 绿色用于深带，Uplift 用于装饰
- 在整个系统的 SoDoSans 上保持“-0.01em”/“-0.16px”的紧密跟踪
- 每个按钮均使用 50 像素的全药丸半径，无一例外
- 应用“transform:scale(0.95)”作为通用按钮活动状态
- 仅为奖励状态仪式时刻保留金币
- 几乎所有事情都可以使用 SoDoSans；仅在奖励社论标题中切换为 Lander Tall Serif；为职业“杯名”时刻保留卡拉姆脚本
- 第 2-3 层低 alpha 阴影，而不是一个较重的投影用于提升高度
- 使用 Frap 圆形 CTA 作为每个购物界面上的持久浮动订单输入
- 让奶油色画布在内容卡之间呼吸——使用空白，而不是分隔线### 禁止事项
- 不要使用纯白色作为页面画布——温暖的奶油温度是承重的
- 不要选择“一牌绿”——四绿体系是有意为之；在任何地方只使用“#006241”会使品牌变得扁平化
- 不要使用金色作为通用口音——它只是一个奖励信号
- 不要将按钮上的角弄成方形 - 50 像素药丸是通用的
- 不要引入渐变填充——整个系统都是色块的
- 不要按大小对 h1 和 h2 进行权重对比 - 层次结构来自权重 + 颜色（600 Starbucks-Green 与 400 Text Black）
- 不要使用纯黑色作为正文 - `rgba(0,0,0,0.87)` 与暖色画布相匹配
- 不要跳过按钮上的“scale(0.95)”主动反馈——这是一个标志性的微交互
- 不要堆叠单一的重阴影；总是层 2-3 低 alpha 层
- 不要将衬线或脚本引入主要购物流程 - 它们分别属于奖励和职业上下文## 8. Responsive Behavior



### 屏幕断点
从组件宽度标记和渐进式导航高度推断：

|名称 |宽度|关键变化|
|------|--------|-------------|
| xs | < 480 像素 |全球导航 64 像素；汉堡菜单；单列布局；药丸按钮全角|
|手机 | 480–767 像素 |全球导航 72 像素；礼品卡网格 2-up；卡垫收紧|
|平板电脑| 768–1023 像素 |全球导航 83px；礼品卡网格 3 合；英雄分裂开始出现|
|桌面| 1024–1439 像素 |全球导航 99px；礼品卡网格 4 合；完全不对称英雄 40/60 |
|超大| 1440 像素以上 |内容上限为“--columnWidthXLarge”；礼品卡网格 5 合；额外的奶油余量|### Touch Targets
- 药丸按钮的“7px 16px”填充尺寸约为 32px 高 — 低于仅触摸表面的 44px WCAG AAA 最小值。在移动设备上，按钮填充可能会在视觉上扩展以满足最小值。
- “56px”处的 Frap 浮动圆形按钮远高于最小值。
- Frap 使用 `--frapTouchOffset: calc(-1 * .8rem)` 将点击区域扩展到视觉边缘之外 8px。
- 表单浮动标签输入在移动设备上增大标签字体大小（基础版为 1.6rem，桌面版为 1.9rem）——更易于在远处点击和阅读。### Collapsing Strategy
- **全局导航高度逐渐缩放**：跨断点 64 → 72 → 83 → 99px，而不是单个值
- **英雄分割崩溃**：40/60 不对称分割 → 在移动设备上堆叠（图像顶部，内容下方）
- **礼品卡网格**：5-up → 4-up → 3-up → 2-up → 1-up 跨断点，调整卡片宽度
- **功能带**：保持全宽，但文本+图像在移动设备上垂直堆叠
- **外边距比例**：随着视口的增长，16px → 24px → 40px
- **奖励 3 列状态面板**：在移动设备上堆叠到单列### Image Behavior
- 英雄产品摄影在移动设备上垂直裁剪得更紧密；内容成为视觉锚点
- 礼品卡插图保留纵横比；卡网格回流焊
- 图像加载时“不透明度 0.3 秒缓入”淡入过渡（防止出现刺耳的弹出效果）
- 奖励应用程序中的手持摄影按比例缩放；从不伸展## 9. Agent Prompt Guide

当优化使用此设计系统生成的现有屏幕时：
1. 一次专注于一个组件
2. 参考本文档中的具体颜色名称和十六进制代码
3. 使用自然语言描述（“温暖的奶油色画布”、“四层绿色系统”）和精确值
4. 普遍保留 50px 药丸 + `scale(0.95)` 活动状态
5. 检查果岭是否映射到其正确的角色（CTA 为绿色强调色，标题为星巴克绿，乐队为 House Green）
6. 不要引入渐变——系统是色块的
7. 全面保持 SoDoSans 跟踪在 `-0.01em` / `-0.16px`### Known Gaps
- SoDoSans 是 Google Fonts 上不可用的专有字体 - 公开实施时，使用 Inter 或 Manrope 作为替代字体并记录交换情况
- Lander Tall（奖励衬线）也是定制的 - 替换为 Iowan Old Style、Lora 或 Source Serif Pro
- 没有为每个交互式表面捕获超出少数记录的特定每个组件动画计时（“--duration：0.4s”、“--iconTransition：所有 escape-out 0.2s”、“--expanderDuration：300ms”）
- 表单错误状态完整样式（红色边框粗细、图标位置）在色调标记上可见，但未详尽提取
- 职业页面特定组件（杯名卡、搜索无线电网格）在令牌名称中引用，但不包含在此提取中
- 星巴克 Visa 卡/星巴克卡 (SVC) 详细的模型规格由 `--svcRoundedCorners` 和 `--svcShadowFilter` 标记暗示，但未完整记录

# Design System Inspired by Mastercard

## 1. Visual Theme & Atmosphere

万事达卡的体验读起来就像一本由柔软的石头和信号橙色制成的温暖的社论杂志。画布是柔和的腻子奶油色（“#F3F0EE”）——不是白色，不是灰色，而是一种感觉像高级年度报告纸张的颜色。在画布之上，所有重要的东西都被塑造成体育场、药丸或完美的圆形。主要的视觉姿态是**超大半径**：英雄带有 40 点角，卡片完全呈药丸形状，服务图像被裁剪成圆形轨道，按钮要么完成药丸，要么紧贴在 20 点处。页面上几乎没有任何尖角。

第二个手势是**轨道和轨迹**。圆形图像蒙版不会静止不动——它们通过细长的、手绘感觉的橙色弧线连接，跨越整个视口宽度，意味着服务的星座而不是列表。每个圆圈都有一个小的附加“卫星”——一个带有箭头图标的白色微型 CTA——像月亮一样停靠在其周边。这是万事达卡当前设计语言最独特的一点：尽管页面是静止的，但圆圈感觉它们在运动。

版式完全以万事达卡专有的几何sans **MarkForMC** 呈现。标题设置为中等权重 (500)，并带有紧密的负字母间距 (-2%)，让他们有信心而不会大喊大叫。正文在同一系列中采用稍轻的字体（450）——您在网络上很少看到这种字体，选择它是因为它读起来比普通的 400 更柔和，而且不会感觉单薄。整个系统——温暖的奶油色表面、药丸形状、圆形肖像、橙色轨道、黑色 CTA——同时给人一种制度化（一个有 60 年历史的支付网络）和社论（一本现代品牌杂志）的感觉，这正是万事达卡想要保持的张力。

**主要特征：**
- 暖奶油色帆布 (`#F3F0EE`) 取代了传统的白色 — 每个表面都是有色的，绝不无菌
- 极端边框半径作为设计语言：40px、99px、1000px占主导地位；任何正方形都是第三方 cookie 横幅
- 圆形图像肖像，附有白色卫星 CTA 和追踪橙色轨道路径
- 幽灵“水印”标题（标题比例上的奶油色文本）分层在圆形肖像后面
- 主体半径为 20 像素的黑色主要 CTA — 橙色 cookie 横幅保留在同意流中
- 浮动药丸状导航，停靠在带有圆肩的视口顶部下方
- 带有小重音点的眉毛标签 + 大写粗体跟踪 - 用作部分类别信号
- 深暖黑色页脚（`#141413`），具有四列链接布局和大型对话标题## 2. Color Palette & Roles



### Primary
- **万事达卡红色** (`#EB001B`)：万事达卡标志的左侧圆圈 - 仅用于品牌徽标，从不用作 UI 颜色。
- **万事达卡黄色** (`#F79E1B`)：万事达卡标记的右侧圆圈 - 仅用于品牌徽标，从不用作 UI 颜色。
- **墨黑** (#141413`)：用于主要 CTA、奶油色标题文本和页脚表面的温暖近乎黑色。稍微温暖（“13”蓝色值接近奶油色），因此在温暖的画布上永远不会感觉乌黑。### Secondary & Accent
- **信号橙** (`#CF4500`)：用于同意操作和眉毛点的烧焦/生锈的 CTA 橙色。比品牌黄色更深，比墨水更亮——它是页面上单一的攻击性颜色，必须谨慎使用。
- **浅信号橙色**（`#F37338`）：一种较浅的胡萝卜橙色，用于旋转木马活动指示器和装饰性轨道弧。始终充当注意力提示，而不是身体颜色。
- **Clay Brown** (`#9A3A0A`)：用于二级链接样式按钮（例如 cookie 详细信息）的深锈色。位于墨水和信号橙色之间。### Surface & Background
- **Canvas Cream** (`#F3F0EE`)：页面画布。温暖、腻子色调，默认的身体背景。所有编辑部分都以此为基础。
- **Lifted Cream** (`#FCFBFA`)：比画布轻一步 — 用于想要感觉像纸放在纸上的嵌套“凸起”部分。
- **白色** (`#FFFFFF`)：保留用于浮动导航丸、模态卡、辅助按钮填充以及附加到图像肖像的小卫星 CTA 圆圈。
- **Soft Bone** (`#F4F4F4`)：在少数组件子区域内使用的冷灰色替代表面。### Neutrals & Text
> **源页面：**主页 (`/`)、`/ payment`、`/pricing`、`dashboard.stripe.com/register/ payments`。### Semantic & Accent
- **链接蓝色** (`#3860BE`)：一种深而略带灰尘的蓝色，用于内联链接和信息标注。足够饱和，可以作为链接阅读，而不是霓虹灯。
- **无价红+黄**：全彩万事达卡标志是该品牌唯一红色和黄色同时出现的地方；它们将身份锁定到页面而不充当 UI 调色板。### Gradient System
万事达卡在核心 UI 中不使用编程渐变。 “渐变”的视觉印象来自两个地方：
- **圆形图像肖像**，其中暖橙色照片主题（卡片、向日葵、饮料）淡入其边缘的奶油色画布
- **深卡片阴影**在提升的内容上（`rgba(0,0,0,0.08) 0px 24px 48px`），在药丸状媒体下方创建柔和的光环## 3. Typography Rules



### 字体家族
- **主要**：`MarkForMC` — 万事达卡专有的几何 sans。页面上的每个标题、正文段落、按钮、导航链接和页脚链接。
- **次要**：`MarkOffcForMC` — 在少数情况下（法律文本、某些形式）使用的“官方”剪辑。
- **后备堆栈**：`SofiaSans、Arial、sans-serif` — Sofia Sans 是一个合理的开源替代品； Arial 是最后的网络安全后备方案。### 字体层级

- **重量 450 为承重**。大多数品牌使用400/500/700；万事达卡使用 450 进行正文，从而营造出异常柔和的阅读语气。将其替换为 400 会扁平化身份。
- **头条新闻上严格的负面跟踪** (-2%) 赋予显示文本编辑密度 - 单词锁定在一起而不是呼吸。
- **仅在眉毛刻度上进行大写跟踪**（14px / 700 / +4% 跟踪）。不要在其他地方使用大写；没有喧闹的章节标题。
- **单一字体系统**。抵制添加第二种字体以进行对比的冲动。对比度来自比例、粗细和字母间距，而不是来自衬线或显示重音。
- **线高比随尺寸下降**。 H1为1:1，H3为1.2，主体为1.4。显示紧密，阅读舒适。### 字体备选说明
MarkForMC 是专有的并获得许可。在无法访问原始内容的情况下重建匹配的美学时：
- **Sofia Sans**（谷歌字体）是最接近的开源匹配 - 它已经在万事达卡声明的后备堆栈中。
- **国米**，体重为 450/500/700，可作为通用替身；预计 x 高度会稍高，字母形状会较宽松。
- **Neue Haas Grotesk** 或 **Geist** 可以近似商业项目的几何感觉。
- 无论使用哪种替代品，保留标题上的 **-2% 字母间距**和 **450 字重**（使用带有可变字体的 `font-weight: 450`，或替换 `font-weight: 400` 并将字母间距收紧 ~-0.5% 进行补偿）。## 4. Component Stylings

- 链接行：白色，粗细450，14px；条目前缀为“需要帮助？”的小图标（支持气泡、卡片、地图图钉、问号）。专栏
- 外部链接标记：链接文本后有一个右上角的小箭头 (`↗`)
- 底行（位于 1 像素白色不透明分隔线下方）：版权 + 隐私小字 + 国家语言药丸下拉菜单 + 四个社交图标（LinkedIn、Facebook、X、YouTube）## 5. Layout Principles



### 间距系统
- **基本单位**：8px（通过 dembrandt 提取和计算样式确认）
- **比例**：8 / 16 / 24 / 32 / 48 / 64 / 96 / 128（8的幂）
- **部分垂直填充**：桌面上主要部分之间的 ~96–128px；移动设备上约为 48–64 像素
- **卡片内部填充**：桌面上为 32–40 像素，移动设备上为 ~24 像素
- **导航顶部边距**：距视口顶部约 24 像素（药丸漂浮，不接触）### 网格与容器
- **最大内容宽度**：约 1200–1280 像素居中，约 48–100 像素水平装订线
- **列模式**：隐含 12 列，但实际布局使用 2-up 不对称（左侧大标题，右侧支持文本）、1-up 全出血（英雄、视频）或交错单肖像放置（服务卡位于不同的网格位置，创造“星座”感觉）
- **页脚网格**：桌面上有 4 个相等的列，在移动设备上折叠为单列折叠式### 留白哲学
万事达卡将空白视为结构，而不是缺失。典型的服务部分有：
- 幽灵标题占据了该部分的顶部~40%（大部分是空奶油）
- 单个圆形肖像位于下方约 60%，左右不对称
- 肖像和下一部分之间有约 300–500 像素的空白画布
这种故意的空虚告诉眼睛“放慢速度，一次阅读一件事”——这与密集的仪表板用户界面相反。### 圆角半径级配
|半径 |使用 |
|--------|-----|
| 3–6 像素 |微小的装饰元素，饼干横幅微芯片|
| 20 像素 |主要和次要主体 CTA（签名按钮半径）|
| 24 像素 |同意/橙色药丸按钮，莫代尔内部芯片|
| 40 像素 | Hero 媒体框架、大截面容器角、H2 药丸标签 |
| 50% |圆形肖像、纯图标按钮、卫星 CTA |
| 99 像素 / 999 像素 / 1000 像素 |完整的药丸形状 - 导航、轮播卡、页脚国家/地区选择器、主内嵌芯片 |

比例尺很不寻常：大多数系统使用 4/8/12/16。万事达卡跳过这些并承诺**小（≤6）、中大（20-40）或全药（99+）**。 8-12 之间的中间地带不存在，这就是为什么 UI 感觉要么“精确且实用”，要么“柔和且具有编辑性”，没有中间地带。## 6. Depth & Elevation

|水平|治疗 |使用 |
|--------|------------|-----|
| 0 |没有影子|默认设置 — 95% 的表面直接位于奶油色画布上 |
| 1 | `rgba(0, 0, 0, 0.04) 0px 4px 24px 0px` |浮动导航丸——几乎没有升力|
| 2 | `rgba(0, 0, 0, 0.08) 0px 24px 48px 0px` |英雄媒体框架，升高的卡片 - 柔软的大半径光环而不是硬滴 |
| 3 | `rgba(0, 0, 0, 0.25) 0px 70px 110px 0px` |稀有的;特征瓷砖上的戏剧性高度|### Shadow Philosophy
万事达卡使用阴影作为**大气缓冲**，而不是定向光。 2 级阴影的宽度为 48 像素，不透明度仅为 8% - 它几乎不作为暗像素存在，但会产生“卡片在画布上方呼吸”的感觉。系统中的任何地方几乎没有尖锐、紧密的阴影。对于功能描述（表单输入、页脚分隔线），边框线优于阴影。### 装饰性深度
- **轨道弧**（橙色光信号，~1px）：追踪跨部分的连接路径
- **幽灵水印标题**：奶油色文本赋予各部分几乎压纸的质量
- **圆形图像淡入淡出**：圆形肖像边缘的暖色调摄影融入画布，暗示柔和的大气深度## 7. Do's and Don'ts



### 推荐事项
- 使用 Canvas Cream (`#F3F0EE`) 作为默认的身体背景 - 绝不是纯白色
- 将服务/功能图像遮罩为完美的圆形，而不是矩形或圆角矩形
- 在每个圆形肖像的右下角附加一个白色卫星 CTA
- 以 MarkForMC 字重 500 设置标题，字母间距为 -2%
- 正文段落使用粗细 450（而不是 400）
- 将主要 CTA 保留为带有奶油色文本的墨黑色药丸（半径 20 像素）
- 仅在同意、法律或合规行动时使用橙色信号
- 将导航作为圆形白色药丸浮动在视口顶部下方，而不是在 y=0 处齐平
- 从三种表面色调构建页面节奏：画布奶油色→提升奶油色→墨水页脚
- 在服务卡之间使用细光信号橙色弧线来暗示连接### 禁止事项
- 不要使用纯白色作为页面背景——它破坏了温暖的编辑基调
- 不要将图像帧舍入 8–16 像素 — Mastercard 使用全圆、40 像素或全圆。中间半径看起来很通用
- 不要使用信号橙色来营销号召性用语 — 它读作 cookie 同意橙色并淡化了合法的颜色信号
- 不要混合字体——没有衬线重音，没有脚本，没有辅助显示字体
- 不要用超过六个顶级链接来挤满导航——该药丸应该给人一种通风的感觉
- 不要放置硬阴影 - 所有高度应使用 48px+ 展开和 ≤10% 不透明度
- 请勿使用大写字母表示任何大于 14px 眉毛标签的内容
- 不要省略眉毛标签前的小重音点 - 这是身份
- 不要将圆形肖像放在网格上 - 它们的魔力来自不对称放置## 8. Responsive Behavior



### 屏幕断点
|名称 |宽度|关键变化|
|------|--------|-------------|
|手机 | ≤ 767 像素 |导航丸仅显示徽标+菜单+搜索；主要链接隐藏在汉堡后面；服务肖像堆叠单列居中；英雄标题从 64 像素下降到约 40 像素；页脚列折叠成垂直手风琴|
|平板电脑| 768–1023 像素 |导航丸显示 2-3 个主要链接被截断；服务肖像排列为 2 幅；英雄标题 ~48px |
|桌面| ≥ 1024 像素 |完整导航，其中 5 个主要链接居中；服务肖像不对称地放置有装饰性轨道线；英雄标题 64px |
|宽| ≥ 1440 像素 |内容最大宽度上限为 ~1280px；排水沟对称生长；轨道线进一步延伸|### Touch Targets
所有交互元素都轻松超过 44×44 像素。卫星 CTA（圆圈 + 箭头）约为 50–60 像素。导航药丸按钮高约 48 像素。移动汉堡包和搜索的尺寸为 48×48px。任何断点处的链接或按钮都不会低于 40 像素。### Collapsing Strategy
- **导航**：整粒药丸 → 紧凑药丸加汉堡包。药丸形状在断点处得以保留——始终呈圆形，始终处于浮动状态。
- **服务网格**：不对称星座→ 2-up → 1-up 堆栈。轨道弧在移动设备上被删除（它们仅适用于不对称放置）。
- **间距**：移动设备上的部分垂直内边距从 128 像素压缩到 48 像素。
- **内容**：两列英雄（标题左/支持文本右）堆叠（标题在顶部，支持文本在下）。
- **页脚**：4 列 → 1 列手风琴，每个部分带有 V 形开关。### Image Behavior
圆形肖像按比例缩放（在每种尺寸下都保持完美的圆形）。英雄视频帧在每个断点处保持 40 像素半径，但帧本身随视口缩小。延迟加载是奶油色模糊占位符的标准配置，可在加载期间保留调色板。## 9. Agent Prompt Guide

# Dig Pre-Flight Check

Use this gate before delivering generated or reviewed UI.

## Required Checks

- Dig Read is stated when the task involves page generation or review.
- Layout and catalog choices are explicit.
- Catalog defaulting is explained when the user did not choose one.
- Dials are stated when the task is broad enough to require judgment.
- Only one base catalog is used per page or coherent component group.
- Required layout slots are implemented.
- Relevant blocks are selected instead of inventing local structures.
- Loading, empty, error, disabled, focus-visible, and mobile states are covered.
- Execution pages are not turned into marketing pages.
- Tables, feeds, and cards are not mixed for one business list.
- Dark and light modes use tokens instead of hard-coded colors.
- Destructive actions have confirmation or a clear recovery path.

## Render Checks

- Catalog render passes visual review.
- Layout render shows complete slots across desktop, tablet, and mobile.
- Block render shows the required state matrix.
- Render output is fresh relative to Markdown and fixture sources.

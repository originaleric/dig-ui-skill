step-timeline

带 status、timing 和可展开详情的有序执行或设置步骤协议。

category: product source: references/blocks/product/step-timeline.md asset source: official compatible catalogs: all preview catalog: dig fixture: step-timeline.json schema version: 2 language: installed

Use when

  • 展示有序步骤、执行节点、设置阶段或审计轨迹。

Avoid when

  • items 是无顺序的同级记录；应使用 table、list 或 feed。

State semantics

StateMeaningTriggerQA
default Timeline row Step exists in run history Sequence is visible.
running Active step Current step is executing Duration can update without shift.
completed Successful step Step finished successfully Completion does not over-emphasize.
error Failed step Step fails Failure detail is adjacent.
collapsed Hidden detail User collapses step detail Status remains visible.
mobile Narrow timeline Mobile breakpoint Metadata stacks in reading order.

Accessibility

  • status 和 order 必须通过文本表达，不能只靠颜色。

Anti-patterns

  • 除非 details 需要，否则不要把每个 step 做成完整 card。

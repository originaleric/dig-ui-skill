settings-row

带 label、description、control、status 和可选危险操作的设置项行协议。

category: product source: references/blocks/product/settings-row.md asset source: official compatible catalogs: all preview catalog: dig fixture: settings-row.json schema version: 2 language: installed

Use when

  • 一个设置项需要稳定 label、说明文本和控制或操作。

Avoid when

  • 用户需要填写多个字段；应使用 form rows 或 form section。

State semantics

StateMeaningTriggerQA
default Editable setting Setting can be changed Control and description align.
enabled On setting Boolean value is true Status reflects enabled value.
disabled Locked setting Policy prevents mutation Current value remains readable.
loading Saving setting Mutation in progress Duplicate save is blocked.
error Failed setting Save or validation fails Recovery action is local.
saved Persisted setting Save succeeds Confirmation is visible but quiet.
mobile Stacked setting Mobile breakpoint Control stacks below copy without overlap.

Accessibility

  • toggle 和 status label 必须保持明确。

Anti-patterns

  • 不要把无关设置混在一行。

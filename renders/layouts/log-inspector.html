Global Rules

  • i18n
    • 所有可见界面文案必须支持中文 / 英文两套语言，语言键使用 `zh-CN` 与 `en`。
    • 文案必须来自语言包、字典或等价的集中资源，不要在 React 组件中直接混写中英文常量。
    • 语言切换控件使用中 / 英或 `zh-CN` / `en` 表达；切换时同步 `document.documentElement.lang` 并持久化到 localStorage 或等价用户设置。
  • Dark / Light 主题
    • 所有界面必须支持 dark / light 两套主题。
    • 主题切换只替换 token、CSS variables、theme object 或等价主题值，不改变组件结构语义。
    • 组件样式必须引用 `--dig-*` token 或项目内主题变量，避免在组件里写死暗色 / 亮色 hex。
  • 按钮与表单控件
    • 所有主按钮、次按钮、图标按钮、表单提交按钮默认使用药丸形态：`border-radius: var(--dig-radius-pill)` 或等价 pill token。
    • 按钮最小高度保持不低于 `44px`，hover / focus 不改变高度、padding 或圆角。
    • 表单 input、select、textarea、combobox 触发器等控件默认使用 token 化背景、边框、文字颜色，并与 dark / light 模式联动。
  • Select（HTML Preview / React）
    • HTML layout 预览：使用原生 `<select class="dig-select">` + `<option>`，配合 `assets/layout-preview-global.css` 中的 `.dig-select` 样式（仅在 `data-global-rules-enabled="true"` 且 layout render 引入该文件时生效；`assets/layout-preview.css` 只保留不含 global 覆盖的基础 primitive）。
    • React 产品实现：使用项目内 React 组件（例如 `Select`、`SelectTrigger`、`SelectContent`、`SelectOption`）表达下拉，不在产品 UI 中直接写裸 `<select>` / `<option>`；避免引入重型第三方 select 库替代基础下拉。
    • select 与 input 同样使用 pill 圆角与 `--dig-control-bg` token。
  • 交互与图标
    • hover / focus 保持克制，优先 color、border、glow、opacity 变化，不做跳动位移。
    • 图标优先 Lucide 线性图标，不用 emoji 式装饰。
    • active 状态比 hover 更深，不做 scale 或 translate 动画。
  • React Select / Option 组件
    • React 表单中的 select / option 必须使用项目内 React 组件实现，例如 `Select`、`SelectTrigger`、`SelectContent`、`SelectOption`。
    • 不要直接使用原生 `<select>` / `<option>` 作为产品 UI 的最终控件。
    • Select 组件必须支持键盘操作、aria 语义、focus-visible、disabled、required、error 状态，并能与表单状态管理集成。

Sources: references/global-rules.md

Recommended Catalogs

DigMono

Applicable Scenarios

  • 集中式 application / audit logs
  • 比 runtime-console 更专注「读日志」而非「管 runs」
  • SRE 排查与关键字搜索

Avoid When

  • 需要 run 列表 + 多面板 orchestration（用 runtime-console）
  • 单次 run 步骤调试（用 agent-run-detail）
  • 短消息 notification 列表

Slots

  • inspector_toolbar required control — 搜索、级别、时间、暂停/流式切换。
  • log_stream required main — 主日志列表，mono 等宽。
  • log_detail optional supporting — 选中行的结构化 detail 或 stack trace。

Layout Rules

  • log_stream 占 ≥70% 高度，toolbar 单行 compact。
  • 每行：timestamp · level · message，level 用 tag 色语义。
  • 支持 pause live tail，状态在 toolbar 明示。
  • 长 message truncate + expand on select，不在列表行内 wrap 十行。
  • 背景不用高对比 zebra 条纹，用 subtle divider。

Responsive Rules

  • Desktop：toolbar + stream + optional bottom/side detail。
  • Mobile：stream full width；detail 为 bottom sheet；toolbar 折叠次要 filter。

QA Notes

  • log 区是否占主导高度。
  • mono 12px 在 mobile 是否可读。
  • ERROR 行是否足够醒目但不整屏红。
  • 切换 catalog 后 level tag 对比度。

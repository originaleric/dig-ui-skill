# 2026-06-01 多工具安装与更新 CLI 落地

## 更新概览

本次更新为 `dig-ui-skill` 增加统一命令行入口 **`dig-ui-skill`**，支持将同一套 skill 资产安装/更新到 Codex、Cursor、Claude Code 三端个人 skill 目录。默认采用 **copy** 安装，更新时覆盖标准资产，**永不覆盖** 用户本地的 `references/global-rules.local.md`。

安装路径：

```text
Codex：       ~/.codex/skills/dig-ui
Cursor：      ~/.cursor/skills/dig-ui
Claude Code： ~/.claude/skills/dig-ui
```

Cursor 额外支持 `--project`，可在目标仓库生成 `.cursor/rules/dig-ui.mdc` 作为项目级硬触发入口；个人 skill 不再写入 `~/.cursor/skills-cursor`（Cursor 内置托管目录）。

## 详细改动

### 1. CLI 入口

新增 `bin/dig-ui-skill.mjs`，提供三个子命令：

| 命令 | 作用 |
|------|------|
| `install <target>` | 首次安装或覆盖标准资产 |
| `update <target>` | 同 install，强制 copy 模式刷新 |
| `status` | 显示各端安装路径、版本、local rules 是否存在 |

支持的目标：`codex`、`cursor`、`claude-code`（别名 `claude`）。

常用选项：

```bash
npx dig-ui-skill install cursor
npx dig-ui-skill install codex
npx dig-ui-skill install claude-code
npx dig-ui-skill install --all --source .
npx dig-ui-skill install cursor --project .
npx dig-ui-skill install cursor --link --source .   # 本机开发 symlink
npx dig-ui-skill update cursor
npx dig-ui-skill status
```

**安装范围**（copy 到目标 skill 目录）：

- `SKILL.md`、`README.md`、`USAGE.md`
- `references/`、`assets/`、`renders/`、`agents/`、`react/`
- `sync-renders.sh`、`sync_renders.py`、`sync_layout_renders.py`
- `validate-dig-layout-preview.mjs`、`package.json`

**更新保护**：

- 若目标已存在 `references/global-rules.local.md`，更新时跳过该文件
- 若本地尚无 local rules，CLI 提示从 `references/global-rules.local.example.md` 手动复制，不自动创建

### 2. Cursor 项目 Rule 模板

新增 `adapters/cursor/dig-ui.mdc`：

- frontmatter 为 Agent Requested（`alwaysApply: false`）
- 正文指向已安装的个人 skill 目录（`{{SKILL_DIR}}` 占位符，安装时替换为实际路径）
- 明确要求先读 `global-rules.md`，再读 `global-rules.local.md`（若存在）

执行 `install cursor --project <path>` 时写入 `<path>/.cursor/rules/dig-ui.mdc`。

### 3. 安装文档

新增 `INSTALL.md`，覆盖：

- 三端快速安装与验证方式
- CLI 选项说明（`--all`、`--link`、`--source`、`--project`）
- 更新策略与 personal global rules 工作流
- 无 CLI 时的手动 copy / symlink 说明

### 4. package.json

- 包名 `dig-ui-skill`，版本 `0.1.0`
- 注册 `bin.dig-ui-skill` → `bin/dig-ui-skill.mjs`
- 增加 `files` 白名单，便于后续 npm 发布
- 设置 `"type": "module"`

## 运维工作流

```text
1. 开发/发布前：node bin/dig-ui-skill.mjs install cursor --source .
2. 日常更新：    npx dig-ui-skill update --all
3. 检查状态：    npx dig-ui-skill status
4. 项目硬触发：  npx dig-ui-skill install cursor --project /path/to/repo
5. 个人偏好：    cp references/global-rules.local.example.md references/global-rules.local.md
```

本地开发调试推荐使用 symlink，避免每次改仓库都要 reinstall：

```bash
npx dig-ui-skill install cursor --link --source .
```

| 检查项 | 结果 |

| `install cursor --source .` → `~/.cursor/skills/dig-ui/SKILL.md` | 通过 |
| `update cursor` 不覆盖已有 `global-rules.local.md` | 通过 |
| 三端 `install` + `status` 路径与版本显示 | 通过 |
| `install cursor --project .` → `.cursor/rules/dig-ui.mdc` | 通过 |

## 价值与影响

- **安装门槛降低**：一条命令完成三端分发，无需手动 copy 或记路径
- **更新可预期**：标准资产可安全刷新，个人 global rules 不会被覆盖
- **Cursor 双通道**：个人 skill（`~/.cursor/skills/dig-ui`）+ 可选项目 rule（`.cursor/rules/dig-ui.mdc`）
- **发布就绪**：package.json 已具备 bin 与 files 字段，后续可直接 `npx dig-ui-skill` 或 npm 发布

本次 **未改动** catalog / layout 渲染链、Global Rules 源文件与 71 套品牌 preview；CLI 为纯安装分发层增量。

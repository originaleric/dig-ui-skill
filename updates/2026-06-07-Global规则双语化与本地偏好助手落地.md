# Global 规则双语化与本地偏好助手落地

## 更新内容

- 将 `references/global-rules.md` 调整为英文 canonical source，并新增 `references/global-rules.zh-CN.md` 作为中文翻译对照。
- 收紧 dark/light 规则：global rules 只定义主题机制，不提供跨 catalog 颜色值；非 `dig` catalog 不得回退到 Dig 深蓝背景。
- 新增 `Layout / Components Consistency` 分区化规则，覆盖 layout shell、header/topbar、footer、sidebar/navigation、main sections、toolbar、collections、cards/panels、forms/settings、responsive behavior 与 CSS primitive discipline。
- 新增 `references/local-rules-builder.md`，让 Codex / Cursor / Claude Code 这类宿主 Agent 能把用户自然语言偏好整理进本地 `global-rules.local.md`，无需额外配置 AI API key。
- 新增 CLI helper：`dig-ui-skill local path/show/init/sync/add --section`，用于稳定地查看、写入和同步用户本地 global rules。
- 更新 README / README.zh-CN / USAGE / INSTALL / Cursor adapter，突出“通过宿主 AI Agent 沉淀个人 UI 偏好”的工作流。
- 更新 layout render 脚本，兼容英文 `Manifest (For Render Injection)` 与中文旧标题。
- 重新同步并校验 20 个 layout preview，确保 Global Rules manifest 与 notes 正常生成。

## 验证

- `./sync-renders.sh --layouts`
- `npm run validate:layouts`
- 使用临时 `HOME` 验证 `dig-ui-skill local path/show/init/add --no-sync/add 默认同步/重复去重/非法 section 报错`

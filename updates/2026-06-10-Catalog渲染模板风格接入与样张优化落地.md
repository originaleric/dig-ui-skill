# Catalog 渲染模板风格接入与样张优化落地

## 更新内容

- 新增 `plans/2026-06-10-Catalog渲染模板风格接入优化方案.md`，明确将 catalog render 从“token 展示页”升级为“catalog 风格样张页”的方向。
- 重构 `sync_renders.py` 的 catalog render 编译逻辑，支持从 catalog markdown 读取 `render.archetype`，并按行业与品牌默认值选择不同样张类型。
- 新增多种 catalog-aware 样张区域：
  - `command-palette-marketing`：用于 Raycast、Cursor、Warp 等开发工具。
  - `media-player-shell`：用于 Spotify、Apple、The Verge 等媒体消费类界面。
  - `creative-canvas-workspace`：用于 Figma、Miro、Webflow 等创作工具。
  - `commerce-dual-track`：用于 Shopify、Airbnb、Nike、Starbucks 等电商与消费品牌。
  - `inbox-productivity`：用于 Superhuman、Notion、Linear、Cal 等效率与协作产品。
  - `finance-mobile-app`：用于 Wise、Revolut、Coinbase、Kraken 等金融产品。
- 更新 `assets/catalog-preview.css`，将共享 preview chrome 与 catalog 内容字体拆开：通用导航、token 表和控制项保持 mono 风格，页面标题、副标题、section 内容使用当前 catalog 字体与字号体系。
- 为不同 `render.archetype` 增加独立 hero typography 节奏，减少 Shopify、Superhuman、Figma、Spotify 等页面的同质化观感。
- 将默认 runtime-console 风格样例替换为更贴近 catalog 场景的样例内容，例如媒体播放器、命令面板、创作画布、商业双轨、效率 inbox 与金融移动端。
- 修复 Raycast、Spotify、Runway、Sanity、Starbucks、Kraken 等 catalog 中深色背景配深色文字、无效 token 或 token 语义映射错误的问题。
- 更新 catalog token 抽取逻辑，只接受 `--dig-*` CSS 变量行，过滤裸 `css` 等无效内容，避免同步到 render 的 `:root`。
- 在 `references/catalogs/README.md` 中补充 `render` 协议说明，并为代表性 catalog 增加 render intent。
- 新增颜色 token 可视化：所有 hex token 值旁显示小圆点，便于快速识别 `--dig-accent`、`--dig-border`、`--dig-grid-line` 等颜色来源。
- 扩展 Key Tokens 表，新增 `--dig-bg-soft`、`--dig-surface-strong`、`--dig-accent-2`、`--dig-border`、`--dig-border-strong`、`--dig-grid-line` 等结构 token，避免页面使用了结构色但 token 表不可见。
- 修复 token 表分隔线断裂问题：恢复 `td.token-val` 的 table-cell 行为，固定表格布局并统一 value 列圆点对齐。
- 优化 hero side 的 Accent / Support / Body / Title 信息行，改为 grid 对齐，保证标签和值在同一层级。
- 为左侧 Contents 导航增加锚点滚动行为，点击 Style Sample、Colors、Key Tokens 可平滑滚动到对应区块。
- 新增 `validate-dig-catalog-preview.mjs`，用于静态校验 catalog render 的 token 完整性、对比度、无效 CSS 噪音和旧模板文案残留。
- 在 `package.json` 中新增 `validate:catalogs`，与已有 `validate:layouts` 形成 catalog / layout 双校验入口。
- 重新同步全量 catalog render，使 73 个预览页使用新的样张结构、token 可视化和锚点导航。

## 关键说明

- The Verge 页面中的紫蓝色 grid 和 border 来自其 catalog token：`--dig-border`、`--dig-border-strong`、`--dig-grid-line` 均为 `#5200ff`，不是模板硬编码。
- Preview 背景由共享 primitive 决定：底色来自 `--dig-bg` / `--dig-bg-soft`，柔光来自 `--dig-accent` / `--dig-accent-2`，网格线来自 `--dig-grid-line`。
- 通用 preview chrome 仍保持统一，保证可比性；样张内容、hero 字体、页面内容字体和组件语义则尽量从 catalog 自身风格出发。
- 当前环境无网络时，`sync_renders.py` 的翻译请求会 fallback 原文；这不影响 token 编译、render 生成和校验结果。

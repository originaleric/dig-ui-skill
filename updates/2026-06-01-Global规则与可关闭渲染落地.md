# 2026-06-01 Global 规则与可关闭渲染落地

## 更新概览

本次更新新增 **Global Rules** 规则层，默认参与 AI 生成/审查与 layout render。跨 catalog 的行为约束（i18n、dark/light、药丸按钮、原生 select 等）从各 catalog 中抽离为独立资产，并支持在审查场景显式关闭。

系统资产链扩展为：

```text
Global Rules：references/global-rules.md（+ 可选 global-rules.local.md）
Catalog：     references/catalogs/*.md → renders/<category>/*.html
Layout：      references/layouts/*.md   → renders/layouts/*.html
```

优先级：**用户 prompt > global-rules.local.md > global-rules.md > catalog > layout/primitives**。

## 分层模型

```text
页面需求 → global rules（跨 catalog 行为）→ layout recipe（信息结构）→ catalog（视觉气质）→ primitive（底层约束）
```

- **Global rules**：i18n、dark/light 双模式、药丸按钮、原生 select、交互与图标纪律
- **Layout**：区域划分、slot、grid、响应式（不变）
- **Catalog**：颜色、字体、surface 等 token（不变）
- **Primitive**：shell、grid、基础 class（`assets/layout-preview.css` 为中性 primitive；global 专属 pill / `.dig-select` 在 `assets/layout-preview-global.css`）

用户明确说「不使用 global / skip global / no global rules」时，本次任务跳过 global rules，只按 catalog / layout / primitives 执行。

## 详细改动

### 1. Global Rules 源文件

新增：

- `references/global-rules.md` — 默认全局规则入口，含 Manifest YAML 供 render 注入
- `references/global-rules.local.example.md` — 本地覆写示例
- `.gitignore` 加入 `references/global-rules.local.md`

Manifest 规则 ID：`i18n`、`theme-mode`、`pill-buttons`、`native-select`、`interaction`。

### 2. 文档更新

- **SKILL.md**：工作流第 4 步默认读取 global rules；说明优先级与跳过条件；交付组合改为 `layout + catalog + primitive + global rules`
- **USAGE.md**：Layout 章节补充 global rules 层、`--no-global` 同步命令与 validator 用法

### 3. Layout Render 链

扩展 `sync-renders.sh` 与 `sync_layout_renders.py`：

```bash
./sync-renders.sh layout dashboard-overview           # 默认含 global rules
./sync-renders.sh layout dashboard-overview --no-global  # 审查对照版
./sync-renders.sh --layouts --no-global
```

**默认 render**（`data-global-rules-enabled="true"`）：

- HTML notes 区新增 **Global Rules** 卡片（规则摘要 + 来源）
- 注入 `<script id="dig-global-rules-manifest">` JSON manifest

**`--no-global` render**（`data-global-rules-enabled="false"`）：

- 不读取 `global-rules.md` / `global-rules.local.md`
- notes 显示 `Global Rules: disabled for review`
- validator 跳过 global-only 检查

> `--no-global` 只影响 layout render 链，覆盖同路径 HTML；catalog HTML 预览暂不改造。

### 4. CSS 与结构校验

- **assets/layout-preview.css** — 中性结构 primitive（按钮 / input 默认 `--dig-radius-sm`，不含 `.dig-select`）
- **assets/layout-preview-global.css** — global 专属样式（pill 按钮、pill input、`.dig-select`）；仅在默认 layout render 引入，`--no-global` 时不加载
- **validate-dig-layout-preview.mjs** — 从 manifest 的 `validate` 字段读取检查项（pill / select）；`data-global-rules-enabled="false"` 时跳过 global-only 检查

### 5. 全量 layout 预览重同步

20 个 `renders/layouts/*.html` 已重新编译，均含 Global Rules 卡片与 manifest。

## 运维工作流

```text
1. 编辑 references/global-rules.md（或复制 example 为 global-rules.local.md 做本地覆写）
2. ./sync-renders.sh layout <slug>  或  ./sync-renders.sh --layouts
3. 打开 renders/layouts/<slug>.html，检查 Global Rules 卡片与三 viewport
4. 审查对照：./sync-renders.sh layout <slug> --no-global
5. npm run validate:layouts
```

本地自定义：

```bash
cp references/global-rules.local.example.md references/global-rules.local.md
```

## 验证结果

| 检查项 | 结果 |
|--------|------|
| 默认 render 含 Global Rules 卡片与 manifest | 通过 |
| `--no-global` 显示 disabled for review | 通过 |
| `npm run validate:layouts`（20 layout） | 0 FAIL, 0 WARN |
| 临时 `global-rules.local.md` 覆写 | 默认 render 展示 local 来源；`--no-global` 不生效 |

## 价值与影响

- **行为可集中维护**：i18n、主题切换、按钮/select 纪律一处定义，AI 与开发不必从 catalog 重复推断
- **审查可对照**：`--no-global` 生成不含 global 的 layout 预览，便于只看结构骨架
- **校验可分层**：global 规则与 layout 结构检查解耦，validator 按 HTML 标记自动切换

本次 **未改动** catalog 同步逻辑与 71 套品牌 preview 的默认行为；global rules 为增量规则层，默认开启，关闭须显式声明。

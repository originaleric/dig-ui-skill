# 2026-05-17 系统 YAML 化与渲染同步脚本升级

## 更新概览

本次更新借鉴了 `awesome-design-md` 的架构理念，对 `dig-ui-skill` 的底层架构进行了深度重构。从原先的“自然语言描述为主”全面过渡为**“Prompt-as-Code”**（机器易读）的格式。同时，我们完善了系统配套的人工及自动化维护工作流。

## 详细改动

1. **全面引入 YAML 映射 (Tokens -> YAML)**
   - 升级了所有 5 个 Catalog 文件 (`runtime.md`, `apple.md`, `mono.md`, `editorial.md`, `wise.md`)。
   - 新增 `typography` YAML 代码块，将繁杂的文本排版（字体、字号、行高、字重、字距）收敛为结构化的组合 Token。
   - 新增 `components` YAML 代码块，为各 Catalog 的主/次按钮、面板、标签等组件建立了精确的尺寸、圆角与颜色绑定。
   
2. **新增响应式行为策略 (Responsive Behavior)**
   - 在每个 Catalog 中加入了跨设备适配的刚性约束。
   - 明确规定了 Desktop, Tablet, Mobile 的断点行为及 UI 折叠逻辑。
   - 强制规定了移动端可点击区域最小 `44px` 以及正文不小于 `16px` 的触控/阅读标准。

3. **渲染页展示升级 (`renders/*.html`)**
   - 移除了底部原本硬编码的纯文本“排版参数表”。
   - 将 HTML 页面的 `Tokens` 区域替换为了最新的 `YAML` 代码片段提示，保证视觉验证页面与底层 Markdown 文档保持理念一致。

4. **提供独立构建工具 (`sync-renders.sh`)**
   - 编写了纯 Shell 驱动的本地自动同步脚本。
   - 支持从 `.md` 中正则提取 `--dig-` 变量，并全自动注入到对应 `.html` 的 `:root` 节点。
   - 支持全量编译与局部模块独立编译（例如 `./sync-renders.sh runtime`）。

5. **编写系统指南 (`USAGE.md`)**
   - 根目录新增了 `USAGE.md`，完整总结了该系统未来维护的 3 种工作流（AI 极速工作流、纯人工 SOP、自动化脚本同步流）。

## 价值与影响

本次重构极大提升了 AI 代理（如 Cursor/Windsurf）在生成 UI 代码时的**确定性**。通过将原本含糊的“大圆角、深色文字”转化为精确绑定的结构化 YAML 语法，团队成员在后续调用 `dig-ui-skill` 开发新页面时，将获得像素级稳定且一致的页面输出效果，大幅降低了后期的“重试”与人工微调成本。

## 增量架构优化（分类隔离与自动繁衍）

1. **目录分层与业务隔离**
   - 为避免模板膨胀导致的混乱，将 `catalogs` 与 `renders` 平铺结构升级为带场景语义的多级目录结构（如 `consumer/`、`other/`）。
   - 该结构强化了 AI 在分析跨文件上下文时的意图推断，使其明确当前界面属于工具后台还是 C 端消费品。
2. **渲染页全自动生成 (Auto-Scaffolding)**
   - 脚本 `sync-renders.sh` 新增智能复制能力：当侦测到新增的 `.md` 字典但缺失 HTML 预览时，将自动选取基线（`runtime.html`）作为底板，复制并重写标题到对应目录，极大缩短了新建一套 UI 风格的操作链路。
